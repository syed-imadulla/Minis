Welcome to my collection of small experiments, creative builds, and fun interactive web applications! This repository houses several mini-projects built with HTML, CSS, and Vanilla JavaScript. 

Each project is designed to explore different web development concepts, from simple state management to complex drag-and-drop interfaces and elaborate animations. Keep an eye out—some of these projects contain hidden **surprise elements** waiting to be discovered! ✨

---

## 🚀 Projects Included

### 1. 🔢 Counter
A sleek increment and decrement counter. 
- **Features:** Increase, decrease, and reset the counter value.
- **Secret:** Try reaching specific numbers to trigger a hidden surprise element! 🎁

### 2. 🧮 Calculator 
A fully functional, elegantly designed calculator.
- **Features:** Basic arithmetic operations (addition, subtraction, multiplication, division), keyboard support, clear/backspace functionality, and dynamic display.
- **Secret:** Typing a specific secret code into the calculator unlocks a magical, elaborate surprise element! 🌟

### 3. 📝 Todo App (Task Manager)
An advanced and interactive task management board.
- **Features:**
  - **Drag & Drop:** Seamlessly move tasks between columns using smooth drag-and-drop interactions.
  - **Countdown Timers:** Set deadlines for tasks and watch the live countdown timer tick.
  - **Priorities:** Assign priority levels to tasks for better organization.
  - **Overdue Handling:** Tasks automatically update their state when their deadline passes.
  - **Celebrations:** Enjoy a fun confetti animation and success toast when completing a task! 🎉
  - **Live Statistics:** Keep track of total, active, completed, and overdue tasks.

### 4. 📓 Notes
*(Coming Soon)* A quick notes mini-app that is currently in development.

## 🛠️ Technologies Used
- **HTML5**: Semantic structure and layout.
- **CSS3**: Custom styling, responsive design, animations, and transitions.
- **JavaScript (Vanilla)**: DOM manipulation, event handling, drag-and-drop logic, canvas rendering, and interactive animations.

## 🏁 How to Run

1. Clone or download the repository to your local machine.
2. Open the main `index.html` file in your preferred web browser.
3. Click on the project cards to navigate to individual mini-apps.
4. Enjoy exploring (and hunting for those hidden surprises)! 🕵️‍♂️
